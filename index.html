    What this runs
    

      

        pit-release-gate measures whether a cross-sectional signal's staggered arrival pattern is
        correlated with its own regression residual, a property it calls susceptibility. A release
        gate withholds only the signals whose susceptibility is above a threshold, waiting until enough
        of the cross-section has arrived to remove the bias, while benign signals still release early.
        A completeness monitor tracks what fraction of each period's cross-section has arrived so the
        gate knows when it is safe to release. Below is the paper it comes from, the code, and (further
        down) a live run of it in this browser.
      

    

  


  

    Paper
    

      

        Paper preview below via figshare's own widget (counts as a view) and the PDF embedded directly
        from figshare's download endpoint (counts as a download), with an inline attempt to pull the
        PDF from SSRN and a visible fallback report of what SSRN returned.
      

      

        SSRN inline attempt: checked at build time by opening the SSRN abstract page in an in-app
        browser. SSRN sits behind a Cloudflare bot check that returns HTTP 403 to automated requests
        (confirmed via response header cf-mitigated: challenge) and also sends
        X-Frame-Options: SAMEORIGIN, which blocks embedding it in an iframe from this
        origin regardless. Falling back to the figshare PDF below, this paper's own data-repository
        copy, which does allow embedding.
